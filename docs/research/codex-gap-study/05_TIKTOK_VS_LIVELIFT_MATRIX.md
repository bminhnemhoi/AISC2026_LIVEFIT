# TikTok versus LiveLift feature matrix

Research date: **2026-10-05**. Repository: `rebuild/livelift-next`. This is research and a proposed product strategy, not implementation or proof of market demand. The [V3 master roadmap](../../roadmap/LIVELIFT_V3_MASTER_ROADMAP.md) governs future work; these reports supply evidence.

## How to read this matrix

TikTok quality is **documented capability breadth**, not authenticated usability or measured success. LiveLift quality derives from inspected code and the limited checks in report 01. “Conditional” means a testable superiority hypothesis, never a completed result. “NOT FOUND” covers the official documentation searched, not all private/coming TikTok features. Every linked TikTok source was accessed 2026-10-05; market/evidence are recorded in reports 02–04 (T18 is US, all other T sources here are VN documentation).

## Matrix decision

Retain the operational plan/decision/actual loop; shrink product packs to show snapshots; make existing provenance a quiet reliability property. Integrate platform analytics only after manual value is proven. Remove unsupported action automation and generic analytics/AI screens from the active product direction. This report recommends dispositions; it does not delete legacy code.

The strongest residual gap relative to TikTok is not globally new: professional rundown tools and Opsique are direct comparators. The next reports apply that stricter novelty and substitute test.
